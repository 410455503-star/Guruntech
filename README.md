# 工程项目管理系统

一款专业的工程项目管理Web应用软件，帮助团队高效管理工程项目、跟踪任务进度、协调资源分配。

## 功能特性

### 📊 仪表盘
- 项目整体概览和统计
- 最近任务动态
- 团队活动时间线
- 关键指标卡片

### 📁 项目管理
- 项目列表（网格/列表视图）
- 项目详情查看
- 项目创建、编辑、删除
- 项目成员管理
- 进度跟踪
- 文档管理

### ✅ 任务管理
- 看板视图（待开始、进行中、已完成）
- 列表视图
- 拖拽排序
- 任务创建、编辑、删除
- 任务分配和优先级设置
- 进度跟踪

### 📈 甘特图
- 时间线可视化
- 项目和任务进度展示
- 缩放控制

### 📹 视频监控
- 萤石云视频接入
- 实时视频观看
- 云台控制（PTZ）
- 摄像头管理
- 项目关联
- 多画面展示

### 👥 人员管理
- 团队成员列表
- 成员信息管理
- 工作量统计
- 角色权限

### 📊 统计报表
- 项目状态分布（饼图）
- 任务完成率（柱状图）
- 项目进度概览
- 成员工作量统计
- 数据导出功能

### ⚙️ 系统设置
- 数据导出/导入
- 数据重置
- 系统信息

## 技术栈

- **前端框架**: HTML5 + CSS3 + JavaScript (ES6+)
- **图表库**: ECharts 5.x
- **图标库**: Font Awesome 6.x
- **数据存储**: LocalStorage
- **路由**: Hash Router

## 快速开始

### 方法一：直接打开
1. 下载或克隆项目
2. 双击 `index.html` 文件
3. 在浏览器中打开即可使用

### 方法二：使用本地服务器
```bash
# 使用 Python
python -m http.server 8080

# 使用 Node.js
npx serve .

# 使用 VS Code Live Server 插件
```

然后在浏览器中访问 `http://localhost:8080`

### 方法三：部署到 GitHub Pages

详见 [DEPLOY.md](./DEPLOY.md) 获取详细的部署指南！

**快速部署步骤：**
1. 在 GitHub 创建新仓库
2. 运行 `deploy.bat` 脚本（Windows）
3. 在仓库 Settings 中开启 Pages
4. 访问 `https://你的用户名.github.io/你的仓库名/`

一键部署脚本已准备好！🎉

## 使用指南

### 1. 仪表盘
打开系统后，默认进入仪表盘页面，可以看到：
- 总项目数、进行中项目、任务统计、逾期任务
- 项目进度列表
- 最近任务
- 团队动态

### 2. 项目管理
- 点击"项目管理"进入项目列表
- 使用筛选器搜索和筛选项目
- 点击项目卡片查看详情
- 点击"新建项目"创建新项目
- 点击编辑/删除按钮管理项目

### 3. 任务管理
- 点击"任务管理"进入任务看板
- 在看板中拖拽任务卡片改变状态
- 点击任务查看详情
- 使用筛选器按项目、优先级、负责人筛选

### 4. 甘特图
- 点击"甘特图"查看时间线视图
- 缩放控制：放大/缩小
- 查看项目任务的时间安排

### 5. 人员管理
- 点击"人员管理"查看团队成员
- 添加、编辑、删除成员
- 查看成员工作量统计

### 6. 统计报表
- 点击"统计报表"查看数据分析
- 查看项目状态分布
- 查看任务完成率
- 导出报表为CSV文件

## 数据管理

### 数据持久化
- 所有数据保存在浏览器 LocalStorage 中
- 刷新页面数据不会丢失
- 关闭浏览器数据保留

### 数据导出
- 进入"系统设置"
- 点击"导出数据"下载JSON文件

### 数据导入
- 进入"系统设置"
- 点击"导入数据"选择JSON文件

### 数据重置
- 进入"系统设置"
- 点击"重置所有数据"恢复初始状态

## 响应式设计

系统支持多种屏幕尺寸：
- 桌面（1200px+）
- 平板（768px - 1200px）
- 移动端（< 768px）

## 注意事项

1. **数据安全**: LocalStorage 数据保存在本地，清除浏览器缓存会丢失数据，请定期导出重要数据
2. **数据容量**: LocalStorage 有容量限制，建议定期清理不需要的数据
3. **隐私模式**: 在无痕/隐私模式下数据不会持久保存
